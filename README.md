# Lozman

Kişisel planlayıcı (iPhone). Planlar, takvim, yerel bildirimler ve Beşiktaş fikstürü.

- Son sürüm: [Lozman.ipa](https://github.com/lozmann/lozmann/releases/latest/download/Lozman.ipa)
- AltStore ile ücretsiz Apple ID kullanılarak yüklenir.
- AltStore kaynağı (güncellemeler için): `https://github.com/lozmann/lozmann/releases/latest/download/source.json`
- `bjk.json` her sabah güncellenir, uygulama Beşiktaş verilerini buradan okur.
